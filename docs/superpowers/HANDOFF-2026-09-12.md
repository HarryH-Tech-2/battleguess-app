# Handoff — Campaign overhaul (paused 2026-09-12)

Session paused mid-verification at the user's request. Nothing is committed yet; the working
tree holds the whole overhaul (~140 changed files, type-check and lint clean).

## What is done

- **Design spec**: `docs/superpowers/specs/2026-09-12-campaign-overhaul-design.md`.
- **Art**: all 67 battle scenes, 23 chapter emblems, 4 commander portraits, onboarding hero and
  app icon regenerated with Higgsfield `z_image` (painterly matte-painting style), downscaled to
  JPEG under `assets/images/{battles,emblems,mascots,art}`. Old isometric PNGs and `civs/` removed.
  Pipeline + prompts + result URLs in `scripts/art/`. Icons rebuilt by `scripts/art/makeAppIcons.js`.
- **Theme**: `constants/theme.ts` (ink/brass/parchment tokens, Cinzel + Nunito via
  `@expo-google-fonts`), dark is default, light "day map" variant kept.
- **Shared UI**: `components/ui/*` (ScreenBackground, Topography, ChunkyButton, StatChip,
  ProgressBar, ProgressRing, Confetti, Dialog, PageHeader, LegalPage, Typography) and
  `components/learn/*` (PathNode, ChapterBanner), `components/lesson/*` (OptionCard, MapTap,
  TimelineSlider, FeedbackSheet).
- **Screens rewritten**: onboarding (2 pages), Learn campaign map (chapter banners + winding
  path, per-continent unlock rule), lesson (hero strip, parchment options, lat/lng map chart,
  brass timeline, combo chip, feedback sheet, quit dialog), lesson-complete (confetti, count-up,
  battle card reveal, rank bar), Quests tab (new), Codex tab + `battle/[id]` detail (new),
  Profile tab (rank, stats, calendar, badges, history), Settings (now a stack screen), Review,
  Choose guide, legal pages, not-found. Tabs are Learn / Quests / Codex / Profile.
- **State**: `UserProgressContext` adds `daily` quest counters, `studiedBattles`, `claimQuest`,
  `dailyQuests`, `claimableQuestCount`; `utils/ranks.ts`, `utils/quests.ts`, `utils/haptics.ts`.
- **i18n**: en rewritten with all new keys; es/fr/ja/ar regenerated to the same 289-key structure.
- **Removed**: `app/profile.tsx`, `app/home.tsx`, `app/(tabs)/settings.tsx`, old Gemini image
  scripts, `utils/imageGeneration.ts`.
